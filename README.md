## Features

- 📚 Share educational resources, including PDFs.
- 🧩 Create interactive educational pages.
- 🌐 Publish public or private content.
- 🤝 Reuse and share resources with other teachers.

## Technology stack

- **Frontend:** SvelteKit and TypeScript
- **Backend:** FastAPI and Python
- **Database:** PostgreSQL
- **Containerization:** Docker

## Project structure

- `frontend/` — SvelteKit application
- `backend/` — FastAPI application
- `docs/` — Project documentation
- `infra/` — Infrastructure configuration

## Getting started

The project is under active development. Local setup and deployment instructions will be documented once the Docker configuration is ready.
